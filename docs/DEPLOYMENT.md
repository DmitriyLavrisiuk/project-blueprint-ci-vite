# Выкатка

Сайт — статика на GitHub Pages: _Заполнить: адрес сайта_.

## Как выкатывается

- Push в main запускает `.github/workflows/pages.yml`: линт, типы, тесты, сборка, публикация. Красный шаг публикацию останавливает.
- Источник Pages в настройках репозитория — GitHub Actions: Settings → Pages → Source.
- Ручной запуск — Actions → Pages → Run workflow.

## Проверки после выкатки

- В Actions прогон Pages зелёный, в Deployments у выкатки — нужный коммит.
- Сайт открывается, картинки и стили грузятся с префиксом подкаталога, в консоли браузера нет ошибок.

## Откат

Re-run прогона Pages на последнем исправном коммите: публикуется его сборка. Затем исправление — обычным коммитом в main.

## Типовые проблемы

Пополняются по случившимся инцидентам, наперёд не выдумываем.
- Пустая страница, нет картинок — путь собран от корня: `base` и `import.meta.env.BASE_URL`, правила — `.claude/rules/pages.md`.
