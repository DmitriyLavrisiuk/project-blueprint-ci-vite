# Обязательные паттерны

## Страница

- Ровно один H1.
- Лендмарки: шапка — `<header>`, навигация — `<nav>`, основной контент — `<main>`, подвал — `<footer>`, боковая колонка — `<aside>`.
- У каждого списка есть пустое состояние.
- Широкий контент — таблицы, длинные ряды — прокручивается в своём контейнере; страница по горизонтали не прокручивается ни на какой ширине от 320px.

## Компонент

- **Адаптируется по ширине своего контейнера, а не экрана** — container queries: один и тот же компонент встаёт в колонку, в сайдбар и на всю ширину, и media query про окно о его месте ничего не знает.
- **Исключения — шапка и подвал сайта**: они стоят на каждой странице один раз и в одном месте, им — медиазапросы по брейкпоинтам из [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md#брейкпоинты-и-движение).
- Значения — только токены дизайн-системы, без литералов цвета и размеров.

## Доступность

- Фокус с клавиатуры виден везде; кольцо фокуса — одно общее правило, компоненты его не снимают.
- Контраст текста — не ниже 4.5:1, крупного текста, значков и границ полей — не ниже 3:1 (WCAG AA).
- Цель касания — не меньше 24×24 px (WCAG 2.2), у основных действий — 48×48, как советует web.dev.
- Картинка со смыслом — с `alt`, декоративная — с пустым `alt`.
- Движение уважает `prefers-reduced-motion`.
