# Компоненты

Один файл — один компонент. Имя файла — имя компонента в коде без префикса проекта, верхним регистром: компонент `faq` → `FAQ.md`. Проверка docs сверяет имя с кодом, если в `.docs-check.json` задано, где искать компоненты. Документ заводится, когда у компонента есть правила сверх его кода: поведение, состояния, решения владельца.
