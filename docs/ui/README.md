# Интерфейс

Документы интерфейса — трёх уровней:
- **основа** — правила для всех компонентов и дизайн-система: файлы этой папки;
- **компонент** — вид и поведение одного компонента: [components/](components/README.md);
- **страница** — состав и порядок секций одного шаблона со ссылками на компоненты: [pages/](pages/README.md).

| Документ                             | Когда читать                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| [PATTERNS.md](PATTERNS.md)           | **перед любым UI-кодом** — обязательные правила для всех компонентов и страниц |
| [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md) | токены, типографика, кнопки, формы, именование классов, темы, брейкпоинты      |
| [components/](components/README.md)  | вид и поведение компонента                                                     |
| [pages/](pages/README.md)            | состав страницы по шаблону                                                     |

## Как решается вид

Вид нового компонента решается артефактом: варианты рядом, на реальных данных, с переключением темы и ширины. Владелец выбирает вариант, код — после его ответа.
