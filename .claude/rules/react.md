# React

- **Один компонент — один файл и одна ответственность;** имя — по смыслу в домене (`PlanSummary`), а не по виду (`BlueCard`).
- **Компоненты shadcn — в `src/components/ui/`:** добавляются `npx shadcn@latest add <имя>` и правятся только ради починки; своё собирается из них рядом, в `src/components/`. После `add` — `npm run format`: код shadcn приходит в своём стиле.
- **Классы Tailwind — целыми литералами** — `bg-success/10`, а не `` `bg-${tone}/10` ``: сборщик находит только литералы. Цвета — семантическими токенами темы (`text-destructive`, `bg-muted`), а не значениями палитры.
- **Компонент адаптируется по контейнеру (`@container`), а не по окну; медиазапросы — только у шапки и подвала:** правило и причина — в `docs/ui/PATTERNS.md`.
- **Тяжёлые данные и редкие экраны — через `import()`,** а не в основном бандле.
- **Состояние, которое переживает перезагрузку, — один хук над `localStorage`:** один ключ, одна схема, миграция при смене формы.
