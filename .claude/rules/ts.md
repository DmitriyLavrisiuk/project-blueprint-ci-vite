# TypeScript

- **`any` — только с причиной:** `// biome-ignore lint/suspicious/noExplicitAny: <почему>`. Данные снаружи — формы, ответы API, `localStorage` — приходят как `unknown` и проходят разбор схемой zod.
- **Тип выводится из источника, а не пишется второй раз:** из схемы — `z.infer<typeof schema>`, из базы — сгенерированные типы, из констант — `as const` и `typeof`. Два описания одного значения расходятся.
- Импорт из `src/` — через `@/`, без цепочек `../../`.
- Что проверяет Biome, здесь не повторяем: правила стиля и линта живут в `biome.json`.
