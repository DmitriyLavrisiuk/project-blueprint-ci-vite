# Тесты

- **Vitest, тест рядом с кодом:** `src/lib/plan.ts` → `src/lib/plan.test.ts`. Все тесты — `npm test`; на коммите идут тесты затронутых файлов.
- **Тестируем чистую логику** в `src/lib/`: расчёты, схемы, разбор и преобразование данных. Интерфейс проверяем глазами в браузере, а не тестами. Регрессию сначала воспроизводим тестом, потом чиним.
- Импорт явный — `import { describe, expect, it, vi } from "vitest"`, без глобалов.
- **Тест не ходит в сеть и не зависит от часов и окружения:** время — `vi.useFakeTimers()` и `vi.setSystemTime()`; модуль, который читает окружение при загрузке, — `vi.stubEnv()`, `vi.resetModules()` и `await import()`, в `afterEach` — `vi.unstubAllEnvs()`.
