# GitHub Pages

- **Сайт живёт в подкаталоге `/<репозиторий>/`:** `base` в `vite.config.ts` — этот путь. Пути, которые код собирает сам, — через `import.meta.env.BASE_URL`: путь от корня на dev-сервере работает, а на Pages даёт 404.
- **Маршруты — хешем, `#/раздел`:** Pages отдаёт `index.html` только на корень подкаталога, и обновление страницы по обычному пути даёт 404.
- Публикует workflow `.github/workflows/pages.yml` из main; выкатки с машины нет.
